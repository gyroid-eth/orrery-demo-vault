## 目標

2026-08-30 の講演用 vault を元に、Biomatter Lab（2026-10-01）のデモ用 vault を作る。参加者が ORRERY の install からしりとり、pdf-mistral、digest-paper、`/log`、Daily Note と Kanban までを、[[はじめに]] のとおりに試せるようにする。

## 議論プロセス

- 講演用 vault には、講演メモ・質疑応答・参加者の困りごと・Web app デモ・note 記事・QR など、その日の講演に固有のノートが多かった。デモで使わないので外し、流れは [[はじめに]] に一本化した
- pdf-mistral は、配布されている Release（v1.1.1）の設定項目に合わせた。この版は図を vault の中にだけ保存するので、出力先を `20_MDPapers/` にして、digest-paper にそのまま渡せるようにした
- 論文は、再配布できる CC BY 4.0 のものを選んだ。Crossref と PDF の本文の両方でライセンスを確かめた
- `/log` を試したところ、手元の Claude Code の個人設定が混ざり、この vault の見出しと違う形でログができた。この vault の `CLAUDE.md` と log の skill の形に書き直した

## 実装内容

- `.obsidian/plugins/pdf-mistral-plugin/` に PDF Mistral (Hi-Res) 1.1.1 を同梱。API キーは空（[[NOTICE]]）
- [[はじめに]]: 手順0〜6 と、各段の「確かめ」。Mac と Windows（WSL2）の両方
- `10_Reference/Papers/`: Onimaru et al. 2016（CC BY 4.0）と [[論文の出典とライセンス]]
- [[タスク]]: デモの各手順をカードにした
- log の skill: 最後に Obsidian で開く手順を、Mac と WSL の両方で動く `obsidian://` の形にした
