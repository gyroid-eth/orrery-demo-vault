# /addtodo

未完了のタスクを Kanban ボードに足す。

- `/addtodo タスク名` — 期限なしで足す
- `/addtodo タスク名 2026-10-01` — 期限つきで足す
- `/addtodo タスク名 ボード名` — ボードを指定して足す
- 引数がなければ、直前の会話・作業からタスク名とボードを推測する

## 手順

1. **ボードを探す**: `01_Planning/` の `.md` のうち、frontmatter に `kanban-plugin: board` があるものがボード。1 つしかなければそれを使う。複数あれば、ボード名とタスクの内容から選ぶ（迷ったら人に聞く）
2. **重複を確かめる**: ボードにタスク名とほぼ同じ未完了のカード（`- [ ]`）があれば、足さずにそのことを伝える
3. **未着手の列を探す**: `## 未着手`（無ければ `## To Do`）。どちらも無ければ、`アイデア` と `完了` 以外の最初の `## ` の列
4. **その列の最後のカードの次の行に足す**:
   ```markdown
   - [ ] タスク名 [[関連ノート]] 📅 YYYY-MM-DD
   ```
   - 期限が無ければ `📅 …` は付けない
   - 会話で扱ったノートがあれば `[[ノート名]]` で結ぶ。無ければ付けない
5. 足した行とボードの名前を伝える

## 書式

- `📅 YYYY-MM-DD` は期限。今日の Daily Note の「タスク」欄は、この期限の順に並ぶ
- 今日の日付が要るときは、`date +%F` の結果を使う（自分の時計を信用しない）

## 例

```
/addtodo 論文ノートを見直す 2026-10-02
→ 01_Planning/タスク.md の ## 未着手 の末尾に
  - [ ] 論文ノートを見直す 📅 2026-10-02
```
