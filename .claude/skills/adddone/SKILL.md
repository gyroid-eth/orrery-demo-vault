# /adddone

終わったタスクを Kanban ボードで完了にする。完了にしたカードは、今日の Daily Note の「今日完了した」に出る。

- `/adddone タスク名` — そのタスクを今日完了にする
- `/adddone タスク名 ボード名` — ボードを指定する
- 引数がなければ、直前の会話・作業からタスク名を推測する
- いくつかの別々の作業を終えたときは、1 つにまとめず、それぞれを別のカードとして完了にする

## 手順

1. **今の時刻を取る**: `date "+%Y-%m-%dT%H:%M"` を実行する（推測しない）。日付の部分を `YYYY-MM-DD`、全体を `YYYY-MM-DDTHH:mm` として使う
2. **ボードを探す**: `01_Planning/` の `.md` のうち、frontmatter に `kanban-plugin: board` があるもの
3. **既存のカードを探す（必ず先に）**: タスク名のキーワードで、ボードの未完了のカード（`- [ ]`）を探す。`[state:: in-progress]` の付いたカードを優先する
4. **見つかったら、そのカードを完了にして移す**
   - `- [ ]` を `- [x]` にする
   - `[state:: in-progress]` があれば消す
   - 会話で扱ったノートがあれば `[[ノート名]]` を足す
   - 行の末尾に `YYYY-MM-DD [done-at:: YYYY-MM-DDTHH:mm]` を足す（既存の `📅 …` は残す）
   - 元の場所からその行を消し、**完了の列**（`## 完了（Done）`、無ければ `## Complete` や `## 完了`）の見出しの下の先頭に入れる。空行を残さない
5. **見つからなければ、完了のカードとして新しく足す**: 完了の列の先頭に
   ```markdown
   - [x] タスク名 [[関連ノート]] YYYY-MM-DD [done-at:: YYYY-MM-DDTHH:mm]
   ```
6. 完了にしたカードとボードの名前を伝える

## 書式

- `YYYY-MM-DD` は完了日、`[done-at:: YYYY-MM-DDTHH:mm]` は完了時刻。Daily Note の「今日完了した」は、`done-at` の日付がその日のカードを、時刻の新しい順に並べる
- Obsidian の上でカードのチェックを入れた場合は、プラグイン（Task Done At）が同じ書式で `done-at` を付ける。agent が書くときも同じ書式にそろえる

## 例

```
/adddone しりとりで通信を確かめる
→ 01_Planning/タスク.md の ## 未着手 に
  - [ ] しりとりで Claude と Codex の通信を確かめる
  を見つけた → 完了にして ## 完了（Done） の先頭へ
  - [x] しりとりで Claude と Codex の通信を確かめる 2026-10-01 [done-at:: 2026-10-01T10:24]
```
